# Leveraging Reinforcement Learning to Solve the Portfolio Selection Problem
This code provides application of Reinforcement Learning technique to solve portfolio selection problem to tackle asset allocation problem and, in order to evaluate the optimality of obtained results, we compare outcomes to benchmark strategy. The code was based on initially proposed RL model by (Tatsat H. et al. 2020) which was implemented for solving Porfolio optimization for cryptocurrencies represented as DQN-based RL approach with the optimal solution given as a policy. The Benchmark portfolio is built following "Buy and Hold" policy, where initial investment is equally distributed among assets at first timestep and kept until the termination point forming equally weighted portfolio.Testing performance is made on two test datasets: including and excluding COVID period. The intention behind subdivision of testing dataset is to understand the ability and extent of the RL model to react to unexpected "Black Swan" events. The model learns over the period of time, develops a policy, the the process of exploitation starrts. The results of the model evaluation on the testing set showed an overall
profit in the pre-COVID period and overall decreasing volatility over the whole period of testing. It can be consluded, that RL model has shown effectiveness in application for portfolio selection problem. Applied DQN RL-based algorithm provided slightly higher returns given significantly lower volatility and much higher Sharpe ratio.
